## 系统简介

本系统面向律师事务所的档案管理场景，解决三个核心问题：

- **归档入口统一** —— 通过开放接口接收业务系统推送的档案元数据与文件，形成可追踪的对接链路
- **全生命周期可控** —— 从接收到检索、借阅、鉴定、销毁，每一步都有状态流转与留痕
- **交付场景就绪** —— 自带部署、升级、回滚与验收所需的基础能力

## 核心功能

| 模块 | 能力 |
| --- | --- |
| 档案接收 | 开放接口接收档案元数据与文件地址，支持推送记录与失败重试 |
| 档案管理 | 列表、详情、检索、补录、状态流转，支持多条件组合筛选 |
| 借阅利用 | 借阅申请、审批、电子借阅链接、访问记录与逾期提醒 |
| 鉴定管理 | 密级、保管期限、开放范围鉴定，含待审批与到期预警 |
| 销毁管理 | 销毁申请、审批与执行记录，全流程可查可追溯 |
| 基础数据 | 全宗、分类、保管期限、存放位置、来源系统 |
| 统计分析 | 档案规模、借阅动态、扫描批次、推送表现的可视化看板 |
| 系统治理 | 用户、角色、权限、配置、操作日志、备份恢复 |

## 技术说明

演示站为**纯前端 Mock** 实现，无需部署后端即可完整演示：

- 页面内拦截 `/api/*` 请求，由本地模拟数据层应答，请求与响应结构对齐真实后端接口
- 模拟数据由后端接口定义反查生成，**分页对象、字段命名与真实系统一致**
- 采用 hash 路由，任意页面均可直接刷新访问，不会出现 404
- 前端技术栈：Vue 3 · Vite · Pinia · Element Plus
